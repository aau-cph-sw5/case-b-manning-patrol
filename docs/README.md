# Documentation

MkDocs site with Material theme.

## Prerequisites

- Python >= 3.13
- [uv](https://docs.astral.sh/uv/)

## Setup

```bash
uv sync
```

## Run

```bash
uv run mkdocs serve
```

Open http://localhost:8000

## Build

```bash
uv run mkdocs build
```

## Deploy

```bash
uv run mkdocs gh-deploy
```
